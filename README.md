# Book Project Kit

> The complete picture-book production system — Drive homebase, GitHub repo, showcase + spread review pages, BookVizion bookshelf, Muse dashboard, cast recipes + character boards, and Lulu print — packaged so a new book starts scaffolded and the work is only story and artwork.

**Branch policy:** work happens on the latest *-vN / project branch. List branches before editing. Never assume the GitHub default is the working line. Working line: book-project-kit-v1 (GitHub default is main).

## The one command

Tell Trinity: **"New book project: \<Title\>"** — the runbook executes: Drive tree, repo, flipbook shelf, showcase + review pages, dashboard, cast files. See [RUNBOOK.md](RUNBOOK.md).

## What's inside

- **[MANIFEST.md](MANIFEST.md)** — every component, its canonical home, and what it governs
- **[RUNBOOK.md](RUNBOOK.md)** — the step-by-step scaffolding procedure with its gates
- **docs/** — the specs: master process, build bible, cover-start, Lulu numbers, character board standard, dashboard spec, Drive tree spec
- **templates/** — the proven Harlow's Helping Paws implementations as the reference: showcase, spread review, the two-book BookVizion flipbook, the character recipe skeleton, and the per-book variable list

## Proven on

- *Harlow's Accidental Journey* — Lois Farrell (Book 1, published on Lulu, Nov 2026)
- *Harlow's Helping Paws* — Lois Farrell (Book 2, in production)

## Rules that travel with the kit

Bookshelf over links · one shared menu everywhere · port gate on flipbook changes · hi-res means a real AI upscale · review pages are frozen snapshots · the author's file is the manuscript of record.
