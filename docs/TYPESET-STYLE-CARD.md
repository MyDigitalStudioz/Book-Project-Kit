# Harlow — Spread Typeset Style Card (one-page reference)

Consolidated 2026-10-28 (Trinity) from the locked print spec + Jon's live typeset questions
that afternoon. Keep open while setting type; everything on this card traces to a source below.

## Typeface
- **Body: Andika Regular, 17 pt, 1.3 leading (= 22.1 pt)** — locked version 7.000 on Vader.
  Title page: Andika 36 pt. No italic runs in the story text — set regular throughout;
  if a future rev adds italics, use true italics, never faux/oblique.
- **Standing second choice: Nunito** (fits the same layout bands at 17 pt; lost the bake-off
  only because its capital I and lowercase l are identical).
- Typographer's quotes OFF before setting (verbatim apostrophes). Do not bake story text
  into art — live type only, via the `type-inventory.json` handoff.

## Color (Trinity recommendation, given to Jon 2026-10-28 — his to lock)
- **Top text treatment: warm-cream GRADIENT FADE, warm ivory `#FAF2E0`** (not a solid
  band, not pure white) — full measured spec in `GRADIENT-FADE-SPEC-2026-10-28.md`,
  locked from Jon's approved S02 Photoshop mockup (version B) on 2026-10-28; same family as the
  warm-cream panels behind the S24 text and the cream pulled from the front cover's sky
  for the title page.
- **Text on the band: warm ink `#2E2A24`** — deep charcoal-brown, not pure black;
  ~13:1 contrast on the ivory.
- **Dusk/evening exception (S12 + the darkening back half):** no band — ivory `#FAF2E0`
  text directly over the sky (the S12 solution, measured 7.4–10.6:1).
- Per-spread alternative: sample the cream straight out of that spread's own sky.

## Placement rules (locked, PRINT-SPEC-PACK §4)
- Text only inside the Lulu safe rects (of the 5250 × 2625 spread): left page
  x 3.6% → 46.4%, right page x 53.5% → 96.3%, both y 7.4% → 92.5%. Text stays 0.5 in
  inside trim and never crosses the fold; split across pages only at a sentence boundary.
- Default text band: top of spread to y32% (S01 + S23 left zone: y40%; S15: ~y36%).
- Fold rule: no main character's face center (Harlow or Lois) inside x 44–56%.
- No glyph row on a character, a picture-panel edge, or a dark/busy patch. A spread that
  cannot clear at 17 pt inside its page gets flagged, not forced.
- **S24:** soft warm-cream caption panel behind each text block (rounded corners, solid
  cream in the book's palette, generous padding, fully inside safe margins).
- Proof rule: text fit is proven ONLY by a rendered proof with text visible (Show-text
  toggle capture), per spread.
